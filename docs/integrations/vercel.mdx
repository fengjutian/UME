The **UME Vercel integration** provisions managed UME access directly from the [Vercel Marketplace](https://vercel.com/marketplace). Installing it creates a UME account for you and injects a `UME_API_KEY` into your Vercel project, so you can add long-term memory to your AI apps and agents in minutes, with no separate signup and billing handled through Vercel.

<Note type="info">
  This is the managed Marketplace integration. If you instead want to use UME with the Vercel AI SDK in code, see [Vercel AI SDK](/integrations/vercel-ai-sdk).
</Note>

## Overview

When you install UME from the Vercel Marketplace:

- A UME account and project are created for you (Vercel Native).
- UME environment variables (`UME_API_KEY`, `UME_ORG_ID`, `UME_PROJECT_ID`, `UME_BASE_URL`) are added to your connected Vercel project.
- Billing is handled through your Vercel account, with no separate UME subscription.

You call UME from your app with the injected key. There is nothing else to wire up.

## Install

<Steps>
  <Step title="Add the integration">
    From the [Vercel Marketplace](https://vercel.com/marketplace), find **UME** and click **Install**. Choose **Create New UME Account** (Vercel Native).
  </Step>
  <Step title="Pick a plan">
    Select **Hobby** (free) or **Starter** ($20/month). You can change this anytime from the installation settings in your Vercel dashboard.
  </Step>
  <Step title="Connect a project">
    Connect the UME resource to a Vercel project. UME injects its environment variables into that project.
  </Step>
  <Step title="Redeploy">
    Redeploy so the variables are available at runtime, or run `vercel env pull` to use them locally.
  </Step>
</Steps>

## Environment variables

The integration sets the following on your connected project:

| Variable | Description |
| --- | --- |
| `UME_API_KEY` | Your UME API key, scoped to the org and project created for this installation. This is what you authenticate with. |
| `UME_ORG_ID` | The UME organization id for this installation. |
| `UME_PROJECT_ID` | The UME project id for this installation. |
| `UME_BASE_URL` | The UME API base URL (`https://api.ume.ai`). |

The API key is scoped to your org and project, so the SDK needs only `UME_API_KEY` to get started.

## Quickstart

Install the SDK:

<CodeGroup>
```bash npm
npm install ume
```

```bash pip
pip install ume
```
</CodeGroup>

Add and search memories using the injected key:

<CodeGroup>
```typescript JavaScript
import MemoryClient from "ume";

const memory = new MemoryClient({ apiKey: process.env.UME_API_KEY });

// Store a memory
await memory.add(
  [{ role: "user", content: "I'm a vegetarian and allergic to nuts." }],
  { userId: "user123" },
);

// Retrieve relevant memories
const results = await memory.search("What are my dietary restrictions?", {
  filters: { user_id: "user123" },
});
console.log(results);
```

```python Python
import os
from ume import MemoryClient

memory = MemoryClient(api_key=os.environ["UME_API_KEY"])

# Store a memory
memory.add(
    [{"role": "user", "content": "I'm a vegetarian and allergic to nuts."}],
    user_id="user123",
)

# Retrieve relevant memories
results = memory.search("What are my dietary restrictions?", filters={"user_id": "user123"})
print(results)
```
</CodeGroup>

See the [platform quickstart](/platform/quickstart) for the full API.

## Plans and billing

| Plan | Price | Memories | Retrieval calls | Projects | Support |
| --- | --- | --- | --- | --- | --- |
| Hobby | Free | 10,000 | 1,000 / month | 1 | Community |
| Starter | $20 / month | 50,000 | 5,000 / month | 1 | Community |

Billing runs through your Vercel account; UME never charges your card directly. You can upgrade or downgrade anytime from the installation's settings in the Vercel dashboard.

## Managing the integration

- **Change plan:** open the installation in your Vercel dashboard and update the billing plan.
- **Open in UME:** use the **Open in UME** link to sign in to the UME dashboard for this installation.
- **Uninstall:** removing the integration deactivates the API key and tears down the resource. Any usage for the current period is invoiced before removal.

## Notes

- The integration creates a **new** UME account for the installation. Linking an existing UME account is not supported yet.
- The injected `UME_API_KEY` is scoped to the org and project created for this installation, so you do not manage keys by hand.
